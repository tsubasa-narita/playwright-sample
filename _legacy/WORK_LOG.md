# SCM Manager - 作業履歴

## プロジェクト概要

テスト用のSCMシステム（受注管理画面）を1画面構成で作成。  
API呼び出しは実装せず、ダミーデータとコンソールログによる疑似API呼び出しで動作する。  
サーバー不要で `index.html` をブラウザで開くだけで動作する静的ファイル構成。

## 技術スタック

| 項目 | 内容 |
|------|------|
| HTML | `index.html` - セマンティック構造 |
| CSS | `style.css` - Vanilla CSS（CSS変数によるデザインシステム） |
| JavaScript | `app.js` - バニラJS（フレームワーク不使用） |
| フォント | Google Fonts - Noto Sans JP |

## 画面構成

### レイアウト
- **ヘッダー** (`header`) — ロゴ、ナビゲーション（ダッシュボード / 受注管理 / 在庫管理 / 出荷管理 / マスタ管理）、通知ベル、ユーザー情報
- **サイドバー** (`aside.sidebar`) — 受注管理サブメニュー、レポート、設定
- **メインコンテンツ** (`main.main-content`) — 以下の要素を含む

### メインコンテンツの構成要素
1. **ページヘッダー** — タイトル「受注一覧」、CSV出力ボタン、新規受注ボタン
2. **サマリーカード** (4枚) — 今月の受注件数、受注金額、処理待ち、納期遅延
3. **検索フィルターパネル** — 受注番号（テキスト）、取引先（ドロップダウン）、ステータス（ドロップダウン）、担当者（ドロップダウン）、受注日範囲（date）、商品カテゴリ（ドロップダウン）
4. **受注一覧テーブル** — チェックボックス付き、ソート可能カラム、ページネーション
5. **モーダル** — 受注詳細表示 / 新規受注登録フォーム（共通モーダルを流用）

## 実装済み機能

### app.js の主要機能

| 関数名 | 説明 |
|--------|------|
| `initApp()` | 初期化。ドロップダウン設定 → ダミーAPI呼び出し → サマリー更新 → テーブル描画 |
| `fetchOrders()` | ダミーAPI: 800ms遅延後に68件の受注データを生成して返す |
| `fetchOrderDetail(orderNo)` | ダミーAPI: 400ms遅延後に受注詳細を返す |
| `generateOrders(count)` | ダミーデータ生成。取引先・商品・担当者をランダムに組み合わせ |
| `searchOrders()` | フィルター条件に基づく絞り込み検索（500ms遅延シミュレーション付き） |
| `clearFilters()` | フィルター条件のリセット |
| `sortTable(key)` | カラムヘッダークリックによるソート（asc/desc切替） |
| `renderTable()` | テーブル行のHTML生成 |
| `renderPagination()` | ページネーションUI生成 |
| `showDetail(orderNo)` | 受注詳細モーダル表示 |
| `showNewOrderModal()` | 新規受注登録モーダル表示 |
| `exportCSV()` | CSV出力（ダミー: トーストのみ） |
| `showToast(message, type)` | トースト通知表示（自動消去） |

### ダミーデータ

| データ種別 | 件数 | 変数名 |
|-----------|------|--------|
| 取引先 | 12社 | `CUSTOMERS` |
| 商品 | 12品目 | `PRODUCTS`（名前・カテゴリ・単価を保持） |
| 商品カテゴリ | 7種 | `CATEGORIES`（PRODUCTS から自動抽出） |
| 担当者 | 6名 | `ASSIGNEES` |
| ステータス | 6種 | `STATUSES`（新規/処理中/出荷準備中/出荷済/完了/キャンセル） |
| 出荷倉庫 | 4拠点 | `WAREHOUSES` |

### CSS デザインシステム（style.css）

- CSS変数（`:root`）でカラーパレット・影・ボーダー半径・トランジションを一元管理
- カラーテーマ: ライトモード基本、ダークサイドバー (`#1e2a3a`)
- ステータスバッジはクラス名に日本語ステータス名を使用（例: `.status-badge.新規`）
- レスポンシブ対応（1100px以下: カード2列、768px以下: サイドバー非表示）
- アニメーション: スピナー、フェードイン、スライドアップ、スライドイン
